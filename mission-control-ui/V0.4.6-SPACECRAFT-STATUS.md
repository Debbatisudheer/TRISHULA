# TRISHULA Mission Control UI V0.4.6 — Spacecraft Status

The Spacecraft Status panel now reads backend-owned runtime subsystem fields:

- Power → `power_status`
- Propulsion → `propulsion_status`
- Thermal → `thermal_status` + `thermal_temperature_c`
- Communication → `communication_status`
- Navigation → `navigation_status`
- Health → `health_status`

The UI does not synthesize these values.

Quick Commands without an implemented physical command path are intentionally disabled. ABORT MISSION calls the real runtime API.
