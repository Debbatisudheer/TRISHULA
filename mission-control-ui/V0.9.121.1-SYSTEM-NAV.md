# TRISHULA V0.9.121.1 — System Navigation

System is now an enabled Mission Control navigation section.

The System page reports only authoritative data already exposed by the Ground/Mission Control APIs:
- Mission Control API reachability
- mission projection availability
- physical runtime API reachability
- telemetry/event/command/alert feed availability
- Mission Control WebSocket live state
- mission health/readiness/freshness
- runtime state/version/sequences/mission time
- Ground data counters

It intentionally does not claim Kafka, PostgreSQL, Redis, Docker, host, or process health because the current UI API does not expose dedicated authoritative component health endpoints.

`Sudheer.Dev` remains in the navbar and footer.
