- Professional mission-data inventory and record evidence layout.
- Telemetry, event, command, and alert counts remain sourced from existing API responses.
- Recent telemetry/activity tables use existing records only.

## System Operations

- Runtime evidence and mission state use existing runtime/dashboard/state responses.
- Ground data-flow counters use existing dashboard/API counters.
- Kafka/PostgreSQL/Redis/host health is intentionally not fabricated because no authoritative per-component health contract is exposed by the current Mission Control API.
