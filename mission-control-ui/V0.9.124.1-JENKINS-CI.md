# TRISHULA Mission Control UI — V0.9.124.1 Jenkins CI

## Scope

This checkpoint adds Jenkins CI configuration around the existing Next.js Mission Control UI. Existing UI source and runtime behavior are unchanged.

## Pipeline coverage

- Windows Jenkins Node agent preflight
- `npm ci`
- TypeScript validation (`npx tsc --noEmit`)
- Next.js production build (`npm run build`)
- Build artifact archival

## Required Jenkins agent

The UI pipeline expects a Jenkins agent labelled:

`trishula-windows-node`

The agent must provide Node.js/npm compatible with the project's `package.json` and lockfile.

Do not mark V0.9.124.1 VERIFIED/FROZEN until the pipeline has actually run successfully on the user's Jenkins agent.
