# TRISHULA V0.9.116.1 — Telemetry Navigation

## Scope

Adds the Telemetry Mission Control navigation module on top of the validated V0.9.115.1 Rover UI.

## Behavior

- Enables the `Telemetry` navigation item.
- Reads telemetry only through the existing Ground telemetry API.
- Groups physical telemetry records into complete ticks using correlation ID, with mission-time/timestamp fallback.
- Shows latest physical state, telemetry history, field inventory, source metadata, and record IDs.
- Does not generate, simulate, or hardcode telemetry values in the UI.
- Missing backend values remain `—`.
- Preserves `Sudheer .Dev` in the navigation and footer.

## Validation

Run in the Windows UCRT64 environment:

```powershell
npm install
npx tsc --noEmit
npm run build
```

Then start the UI against the running Ground Data Service and verify the Telemetry tab shows live physical records.
