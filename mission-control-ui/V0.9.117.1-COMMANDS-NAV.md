# TRISHULA V0.9.117.1 — Commands Navigation

## Scope
- Enables the Commands Mission Control navigation module.
- Reads command lifecycle views from `GET /v1/missions/TRISHULA/commands?limit=50`.
- Dispatches operator commands through the real `POST /v1/missions/TRISHULA/commands` Ground API.
- Does not fabricate command execution; execution is shown only when Ground lifecycle/reconciliation reports it.
- Preserves Mission, Spacecraft, Rover, and Telemetry modules.
- Changes developer identity from `Sudheer .Dev` to `Sudheer.Dev` in navigation/footer.

## Existing Ground contract used
- GET `/v1/missions/{missionID}/commands`
- POST `/v1/missions/{missionID}/commands`

## Validation
Full Next.js dependency/build validation was not available in the packaging environment because dependencies were not installed. Validate with `npm install`/`npm ci`, `npx tsc --noEmit`, and `npm run build` in the user's Windows environment.
