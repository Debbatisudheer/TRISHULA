# V0.9.118.1 — Alerts Navigation

Built additively on V0.9.117.1 Commands Navigation.

## Scope
- Enables the Alerts navigation item.
- Adds a dedicated Alert Operations view.
- Uses the existing Ground-authoritative `/v1/mission-control/alerts` data already loaded by the application.
- Displays active alerts, severity breakdown, lifecycle/history, subsystem information, and Ground/event-feed connectivity.
- Does not create synthetic alert states or fabricate alert records.
- Preserves `Sudheer.Dev` in the navigation/footer.
