# V0.9.122.1 — Vikram Navigation

Adds a dedicated **Vikram Lander** Mission Control navigation section between Spacecraft and Rover.

## Data policy
- Uses only existing Ground mission-state, dashboard, telemetry, alert, and event data.
- No synthetic Vikram telemetry is generated by the UI.
- Missing Vikram backend data remains `—` / `Not supplied`.
- The Rover → Vikram → Ground flow is represented from authoritative fields when supplied.

## Navigation
Mission → Spacecraft → Vikram → Rover → Telemetry → Commands → Alerts → Ground Station → Data → System

## Validation
Build and runtime validation must be performed in the user's Windows UCRT64 environment against the running Ground service. This patch does not claim those external runtime results.
