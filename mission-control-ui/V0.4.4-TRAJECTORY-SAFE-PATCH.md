# TRISHULA Mission Control UI V0.4.4 — Trajectory Safe Patch

This package is based on the original frozen V0.4.4 UI baseline.

## Data-path safety

- `app/page.tsx` is unchanged from the original V0.4.4 baseline.
- `lib/api.ts` is unchanged from the original V0.4.4 baseline.
- The existing telemetry refresh, state aggregation, WebSocket handling, API routes, event feed, alerts, and mission-state logic are preserved.

## Central visualization-only change

Only `components/mission-visualization.tsx` is changed.

The physical telemetry positions already supplied by the existing UI are projected into a readable mission view:

- green solid path: previously received physical positions
- cyan dashed path: newest physical positions
- green/cyan dots: actual telemetry positions
- Earth orbit is visually expanded so small real orbital motion is visible
- Earth-to-Moon distance is compressed for readability
- no future trajectory is generated
- no timer moves the spacecraft
- no synthetic telemetry is created

The visualization is therefore dependent on the existing real telemetry data path. If the Ground API currently reports zero accepted telemetry, the UI will correctly show no spacecraft telemetry until the physical uplink sends records.
