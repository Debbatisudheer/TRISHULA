# TRISHULA V0.9.124.1 — Jenkins CI Root

This package keeps TRISHULA under one root folder.

- `backend/` — existing backend project plus its Jenkins CI configuration.
- `mission-control-ui/` — existing Mission Control UI plus its Jenkins CI configuration.
- `Jenkinsfile` — root CI orchestration entry point.

Existing application source was not intentionally restructured or rewritten.
Security remains excluded from the active roadmap.

Use the root `Jenkinsfile` as the Jenkins pipeline entry point.
