# TRISHULA V0.9.49 — Ground Station Core + Packet/Frame Processing

## Baseline

V0.9.48 is the frozen physical landing / surface-contact baseline. V0.9.49 is additive and does not alter the physical landing implementation.

## Scope

V0.9.49 establishes the C++ ground-station transport core for receiving spacecraft/rover downlink frames and turning them into validated ground packets.

The path is:

```text
Vehicle / Rover
      ↓
Ground packet
      ↓
Space-link packet encoding
      ↓
Frame sequence + CRC32
      ↓
GroundStation::ingest_frame()
      ↓
CRC / version validation
      ↓
Packet decode
      ↓
Stream sequence validation
      ↓
Duplicate / out-of-order detection
      ↓
Ground receive queue
      ↓
Ground processing stages
```

## Implemented components

- `GroundPacketType`
- `GroundPacketPriority`
- `SpaceLinkPacketHeader`
- `GroundPacket`
- `SpaceLinkFrame`
- CRC32 calculation
- packet encode/decode
- frame encode/validation
- ground-station receive queue
- per-stream sequence tracking
- duplicate detection
- out-of-order detection
- queue-capacity protection
- ground-station statistics

## Physical-data rule

This milestone is a transport boundary. It does not manufacture mission telemetry or advance spacecraft state. The physical simulation remains the authoritative source of vehicle state.
