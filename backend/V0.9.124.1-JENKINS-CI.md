# TRISHULA V0.9.124.1 — Jenkins CI Foundation

## Scope

This checkpoint adds Jenkins CI configuration around the existing TRISHULA backend. It does not change mission logic, physics, APIs, tests, database schemas, or runtime behavior.

## Pipeline coverage

- Jenkins Windows/UCRT64 agent preflight
- CMake configure
- C++ Release build
- CTest regression suite
- Ground Data Service `go test ./...`
- Ground Data Service `go vet ./...`
- CI artifact archival

## Required Jenkins agent

The backend pipeline expects a Windows Jenkins agent labelled:

`trishula-windows-ucrt64`

The agent must expose MSYS2 UCRT64 at the configured `MSYS2_HOME` path (default in the Jenkinsfile: `C:\\msys64`). It also needs the required Go toolchain and CMake available on PATH.

## Acceptance rule

Do not mark V0.9.124.1 VERIFIED/FROZEN until the pipeline has actually run successfully on the user's Jenkins agent and the authoritative Windows/UCRT64 CTest regression passes.
