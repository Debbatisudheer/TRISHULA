# TRISHULA V0.9.50 — Ground-to-Spacecraft Command Boundary

## Purpose
Extend the V0.9.49 ground-station core into a real command boundary for the physical spacecraft simulation.

## Design
Ground commands targeting VIKRAM are validated for target, sequence, opcode, parameter bounds, and propagation duration before being translated into `PropulsionCommand` and applied to the existing `SimulationEngine`.

Supported physical commands:
- `COAST`: advances the existing physical simulation with zero commanded thrust.
- `MAIN_ENGINE`: applies bounded throttle and body thrust direction for a bounded physical duration.
- `RCS`: applies a bounded non-zero body RCS force for a bounded physical duration.

The link rejects replayed/non-increasing sequence numbers and rejects invalid commands before simulation state changes.

## Integrity rules
- No timer-based mission progression.
- No fake spacecraft state.
- No synthetic telemetry used to claim physical actuation.
- No teleportation or state reset.
- Existing V0.9.49 functionality remains additive and unchanged.

## Validation
Dedicated V0.9.50 campaign verifies physical state change, physical coast propagation, sequence replay rejection, pre-actuation parameter rejection, and target validation.
