# TRISHULA V0.9.107.1 — Ground Ingestion Queue Pressure Observability

## Baseline

V0.9.106.1 — Ground ingestion queue DSA optimization.

## Capability added

The telemetry, event, and command ingestion pipelines now expose two read-only queue-pressure metrics:

- `available_capacity()` — remaining queue slots before the configured capacity is reached.
- `capacity_utilization()` — queue occupancy divided by configured capacity.

The existing FIFO behavior, capacity rejection behavior, duplicate handling, ordering checks, and command-ID tracking are unchanged.

## Safety behavior

A zero-capacity configuration reports zero available capacity and `1.0` utilization, avoiding division by zero.

## Validation added

A dedicated `trishula_ground_ingestion_queue_pressure` campaign verifies:

- telemetry pressure metrics
- event pressure metrics
- command pressure metrics
- recovery of available capacity after dequeue
- zero-capacity behavior

## Expected validation

```bash
rm -rf build

```

V0.9.107.1 is considered validated only after those runtime checks pass in the target UCRT64 environment.
