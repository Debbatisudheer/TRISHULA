# TRISHULA V0.9.102 — Mission Control Alert Lifecycle

## Scope
Adds operational lifecycle management to V0.9.101 alerts: ACTIVE, ACKNOWLEDGED, CLEARED.

## APIs
- GET /v1/mission-control/alerts
- GET /v1/mission-control/alerts/{alertID}
- POST /v1/mission-control/alerts/{alertID}/acknowledge
- POST /v1/mission-control/alerts/{alertID}/clear

Lifecycle actions are persisted as durable event records and replayed during startup restoration. Acknowledgement and clear operations are idempotent for already-acknowledged/already-cleared alerts.

## Real-time
Lifecycle changes use the existing `mission_control.alert` WebSocket envelope with stream version v0.9.102.
