# TRISHULA Ground Data Service — V0.9.103

## Mission Control Alert Detail & Audit

V0.9.103 extends the verified V0.9.102 alert lifecycle with read-only operational inspection.

### APIs
- `GET /v1/mission-control/alerts/{alertID}/detail`
- `GET /v1/mission-control/alerts/{alertID}/history`

### Detail
Returns the current alert projection plus its lifecycle audit entries.

### Audit
Lifecycle records are selected by the alert ID carried in `fields.alert_id`, then ordered deterministically by mission timestamp, sequence number, and record ID.

### Compatibility
Existing alert lifecycle mutation APIs remain unchanged. The WebSocket alert stream remains `v0.9.102`; V0.9.103 adds read-only detail/audit APIs and updates the HTTP API contract version.
