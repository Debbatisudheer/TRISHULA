# TRISHULA V0.9.99 — Live Telemetry Streaming

V0.9.99 builds on the complete V0.9.98 baseline and adds the live telemetry projection from the Kafka consumer to the Mission Control WebSocket gateway.

## Flow

Kafka -> KafkaConsumer -> RecordRouter -> accepted telemetry -> WebSocket Gateway -> Mission Control clients

The consumer remains responsible for validation/routing and the WebSocket gateway remains a transport boundary. PostgreSQL, Redis, Kafka, command execution, scheduling, DLQ, and the C++ vehicle side are preserved from V0.9.98.

## WebSocket telemetry message

`type=mission_control.telemetry`, `stream_version=v0.9.99`, `protocol_version=trishula-ws-v1`, plus mission/source/record/sequence/timestamp/correlation and telemetry fields.
